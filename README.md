# 🚗 Road Accident Analysis Dashboard

## 📌 Project Overview

The **Road Accident Analysis Dashboard** is an interactive data analytics project designed to analyze road accident data and identify important patterns related to accident severity, vehicle types, road conditions, locations, and time periods.

The main objective of this project is to transform raw accident data into meaningful insights that can help understand **when, where, and under what conditions road accidents are more likely to occur**.

The dashboard provides a clear overview of accident trends through KPIs, charts, maps, and interactive filters.

---

## 🎯 Project Objectives

The dashboard was developed to answer key analytical questions such as:

* How many accidents and casualties occurred?
* What is the distribution of casualties by accident severity?
* Which vehicle types are involved in the highest number of casualties?
* How do current accident figures compare with the previous year?
* Which road types have the highest number of casualties?
* How do road surface and weather conditions affect accidents?
* Are more accidents occurring in urban or rural areas?
* How do accident patterns change across different months?

## 📊 Dashboard Features

### Key Performance Indicators (KPIs)

The dashboard highlights important metrics such as:

* Total Casualties
* Total Accidents
* Fatal Casualties
* Serious Casualties
* Slight Casualties
* Year-over-Year comparison

### Analytical Views

The dashboard analyzes casualties and accidents based on:

* 🚘 Vehicle Type
* 🛣️ Road Type
* 🌧️ Road Surface Condition
* ☀️ Weather Condition
* 💡 Light Condition
* 🏙️ Urban vs Rural Location
* 📅 Monthly Trends
* 📍 Accident Location

Interactive filters allow users to explore the data based on different conditions and time periods.

---

## 💡 Key Insights

The analysis helps identify several important road accident patterns:

* Slight casualties account for a major share of total casualties compared with serious and fatal casualties.
* Certain vehicle categories contribute significantly more casualties than others.
* Accident frequency varies across different road types.
* Urban and rural areas show different accident patterns.
* Road surface, lighting, and weather conditions influence accident occurrence.
* Monthly trend analysis helps identify periods with relatively higher accident activity.
* Comparing current-year and previous-year data makes it easier to identify changes in accident trends.

These insights can help authorities focus road-safety measures on higher-risk locations, road conditions, vehicle categories, and time periods.
